# Trademark Policy

This is a practical project policy, not a full legal trademark license.

The code is open source. The Bichess name, logos, domains, hosted service identity, and official event names are controlled project assets.

For broader project direction and public-brand transition boundaries, see `docs/project-direction.md`.

## Allowed Uses

You may use the Bichess name to:

- refer to the official project
- link to `bichess.org`
- describe compatibility with Bichess protocols or data formats
- state that your work is a fork of Bichess
- discuss, review, criticize, or teach the project

## Not Allowed

You may not use the Bichess name, logo, or confusingly similar branding to:

- imply your fork is the official Bichess project
- impersonate `bichess.org`
- run a competing hosted service under the Bichess name
- publish packages or binaries that appear official without permission
- imply endorsement, sponsorship, or affiliation without permission
- use Bichess branding for scams, malware, cheating tools, or misleading services

## Forks

Forks are allowed under GPL-3.0-or-later.

Forks should use a distinct name and clearly state that they are not the official Bichess project.

Acceptable:

> "MyProject is a fork of Bichess."

Not acceptable:

> "Bichess Pro" as an unofficial hosted service that users could confuse with `bichess.org`.

## Events And Sponsorships

Official Bichess tournaments, ladders, engine events, and sponsorship packages require maintainer approval.

Sponsors may receive approved logo placement or naming rights for a specific event, but sponsorship does not transfer ownership of the Bichess name or brand.
