# Repository Policy

Mistboard is a public open-source repository.

This document describes the public repository posture for contributors.

The project is licensed as AGPL-3.0-or-later. Keep dependency choices compatible with that posture unless the project strategy changes explicitly.

The workspace packages are still marked `"private": true` in `package.json` files. That setting prevents accidental npm publishing; it is not a GitHub repository visibility policy.

For product direction, licensing, branding, reference, roadmap, and monetization boundaries, see `docs/project-direction.md`.

## Governance Boundary

Mistboard is founder-led. Open source gives users the right to inspect, run, modify, and fork the code under AGPL-3.0-or-later. It does not transfer control of:

- the `mistboard` name
- `mistboard.com` and related domains
- trademarks and logos
- official package names and publishing credentials
- the hosted service
- production infrastructure and databases
- official bot registries, ladders, tournaments, and sponsorships
- roadmap and release authority

Root policy files define the operating model:

- `GOVERNANCE.md`
- `CONTRIBUTING.md`
- `SECURITY.md`
- `TRADEMARK.md`
- `SPONSORSHIP.md`
- `CODE_OF_CONDUCT.md`
- `docs/project-direction.md`
- `docs/documentation-policy.md`

Public docs should be contributor-safe. Internal strategy, sponsor planning, legal/entity planning, operational handoffs, and credentials belong outside the public repository.
