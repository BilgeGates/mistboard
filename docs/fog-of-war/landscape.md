# Related Work

This page is a neutral pointer to related public work. Internal analysis belongs outside the public repository.

## Fog Of War Chess

Fog of War chess is a hidden-information chess variant where each player sees only squares their own pieces can legally see. Public explanations and playable implementations exist on chess-variant sites and mainstream chess platforms.

Useful comparison points for contributors:

- check and checkmate rules differ across implementations
- king-capture rules must be explicit
- castling and en passant need hidden-information-specific tests
- live clients must not receive hidden truth and hide it visually

## Adjacent Games
