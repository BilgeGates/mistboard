# Public Documentation Topics

This page lists public documentation topics that are useful to users and contributors.

Internal publishing and distribution plans belong outside the public repository.

## Project Description

Bichess is:

- a Fog of War chess site
- server-authoritative about hidden information
- open source
- independent from lichess, chess.com, and other platforms
- focused on play, replay, reveal, and Fog-specific correctness

## Useful Public Topics

Good public docs include:

- rules pages
- examples from positions or games
- postgame reveal explanations
- benchmark summaries with reproducible methods
- technical writeups about `PlayerView`, hidden-information safety, and FOW engine design
- neutral notes connecting Fog of War chess to related hidden-information games

## Quality Bar

Public content should be useful even if the reader never becomes a Bichess user.

Avoid:

- hype without evidence
- claims of engine strength without benchmark context
- private operating plans
- anything that makes contributors feel they are reading internal notes by accident
