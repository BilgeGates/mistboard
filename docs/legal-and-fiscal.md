# Funding Policy

This document describes the public funding posture for Bichess. It is intentionally limited.

It is not legal or tax advice. Any legal entity, tax, prize, sponsorship, or fiscal-hosting decision should be reviewed with qualified counsel or a CPA before money moves.

## Public Position

Bichess is a founder-led open-source project.

The code is public under GPL-3.0-or-later. The official project identity, domains, trademarks, hosted service, package publishing, production infrastructure, official events, sponsorships, and roadmap remain controlled project assets.

## Funding Principles

- Sponsorships support specific Bichess work, events, infrastructure, or community activities.
- Sponsorships do not buy roadmap control, tournament results, benchmark results, private data access, commit rights, release authority, or trademark ownership.
- Meaningful sponsorships should be disclosed.
- Personal-wallet donations should be avoided for public project funding.
- If third-party payment or fiscal-hosting infrastructure is used, it is a payment/admin rail only.

## Tax-Deductibility

Unless explicitly stated otherwise by an approved fiscal host or legal entity, Bichess sponsorships are not tax-deductible charitable donations.

Sponsors should treat contributions according to their own accounting and tax advice.

## Tournament Funds

If Bichess runs prize events, tournament funds should use a clean payment rail that can handle sponsor receipts, prize payments, and recipient paperwork.

Before any prize event with material money, publish event-specific terms covering:

- sponsor terms
- prize terms
- sponsor placement
- payment processor or fiscal host
- tax/reporting responsibilities

Private funding and entity-planning notes belong outside the public repository.
