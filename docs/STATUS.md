# Status

playable, open the site; for active work and known issues, see
[GitHub issues](https://github.com/brianhliou/mistboard/issues). The durable docs
are under [docs/](README.md), starting with [ARCHITECTURE.md](ARCHITECTURE.md)
and [rules.md](rules.md).
