# Fog assets

## fog.webp

- Source: Pixabay video #247797, "smoke fire dark overlay"
  https://pixabay.com/videos/smoke-fire-dark-overlay-247797/
- License: Pixabay Content License — free for commercial use, no attribution required.
  https://pixabay.com/service/license-summary/
- Processing: center-cropped to square, scaled to 256×256, 7s loop @ 20fps,
  0.5s cross-fade seam for seamless looping, encoded as animated WebP (lossy q75).

## mistveil.webp

- Source: AI-generated, Mistboard original.
- Pipeline:
  1. Static frame generated by OpenAI gpt-image-2 (1024×1024) with a tileable
     atmospheric-mist prompt — see `scripts/pixel-gen.mjs` style entries
     and `apps/web/src/pixel-lab.ts` for prompt provenance.
  2. Animated to MP4 via Wan 2.2 i2v-fast on Replicate
     (`scripts/video-gen.mjs`).
  3. Palindrome loop (forward + reverse concat) applied via ffmpeg for
     mathematically seamless looping (`scripts/loop-video.mjs`).
  4. Encoded to 256×256 12fps animated WebP via img2webp (lossy q60, mixed).
- License: CC-BY 4.0 — free for any use with attribution to Mistboard.
  Prompts + pipeline are documented in the repo for full reproducibility.
