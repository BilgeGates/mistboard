# Fog assets

## fog.webp

- Source: Pixabay video #247797, "smoke fire dark overlay"
  https://pixabay.com/videos/smoke-fire-dark-overlay-247797/
- License: Pixabay Content License — free for commercial use, no attribution required.
  https://pixabay.com/service/license-summary/
- Processing: center-cropped to square, scaled to 256×256, 7s loop @ 20fps,
  0.5s cross-fade seam for seamless looping, encoded as animated WebP (lossy q75).

## mistveil/ (64 tiles)

- Source: AI-generated, Mistboard original.
- Approach: ONE continuous 1024×1024 atmospheric mist image, pre-sliced
  at build time into 64 named 128×128 tiles (`f0r0.webp` through
  `f7r7.webp`). Each fog-hidden square gets a class like `fog-tile-f3r5`
  via `fogHiddenClass()` in `@mistboard/board-render/interactive`, and CSS
  maps each class to the matching tile URL. Adjacent fog squares show
  visually continuous mist (because their tiles are adjacent slices of
  the same source) instead of 64 identical copies of one tile. No JS
  positioning, no render race — the URL resolves synchronously at the
  first paint.
- Pipeline:
  1. Static image generated by OpenAI gpt-image-2 (1024×1024) with a
     continuous-mist prompt — see `scripts/pixel-gen.mjs` for invocation.
  2. Pre-sliced into 64 tiles via `scripts/slice-fog.py`.
  3. Tiles encoded as WebP at q85 (~4 KB each, ~256 KB total).
- License: CC-BY 4.0 — free for any use with attribution to Mistboard.
  Prompts + pipeline documented in the repo for full reproducibility.

## mistveil.webp (full image)

- The 64 tiles restitched back into the original continuous 1024×1024 image via
  `scripts/assemble-fog.py` (inverse of `slice-fog.py`). The xiangqi boards
  render fog as one masked SVG region, not per square, so they overlay this
  single texture instead of the per-square tiles. Same art, same license; lets
  fog stay one global setting that renders on every board size.
